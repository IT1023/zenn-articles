# ENGLISH
Most dark mode tutorials stop after toggling a CSS class.

In production, however, there are several additional concerns:
* Persisting the user's preference
* Respecting the operating system theme
* Preventing rapid repeated toggles
* Keeping the implementation reusable
* Maintaining accessibility
* Testing the behavior

This implementation addresses all of these using a reusable custom hook.

# Step 1: Designing the Hook

Rather than placing the logic inside the component, everything lives inside a dedicated hook.

The hook exposes a very small API:
```
type TTheme = "light" | "dark";
export interface UseThemeReturns {
  currentTheme: TTheme;
  toggleTheme: () => void;
}
```
By exposing only the current theme and a toggle function, the presentation layer remains completely independent from the implementation.

# Step 2: Determining the Initial Theme

When the application loads we first attempt to restore the previously selected theme.
```
const THEME_STORAGE_KEY = "theme";

const fetchInitialTheme = (): TTheme => {
  const localTheme = localStorage.getItem(THEME_STORAGE_KEY);

  if (localTheme && ["light", "dark"].includes(localTheme))
    return localTheme as TTheme;
};
```
If no saved preference exists, we fall back to the browser's preferred color scheme.

```
const matchMedia = window.matchMedia(
  "(prefers-color-scheme: dark)"
);

if (matchMedia.matches)
  return "dark";

return "light";
```
This allows first-time visitors to automatically receive the theme they already use at the operating system level.

# Step 3: Persisting Theme Changes

Whenever the theme changes, two things need to happen:
* Save the preference
* Update the document root
````
useEffect(() => {
  localStorage.setItem(
    THEME_STORAGE_KEY,
    currentTheme
  );

  document.documentElement.classList.toggle(
    "dark",
    currentTheme === "dark"
  );
}, [currentTheme]);
````
Using the <html> element allows Tailwind's dark: variants to work throughout the application without additional configuration.

# Step 4: Preventing Rapid Theme Switching

Users can click much faster than we expect.

Instead of allowing dozens of state updates, the toggle action is throttled.
```
// Throttle
export const throttle = <T extends (...args: unknown[]) => unknown>(
  fn: T,
  cooldown: number = 1000,
) => {
  let lastCalled: number = 0;
  return (...args: Parameters<T>) => {
    const now = Date.now();
    if (now - lastCalled < cooldown) return;
    lastCalled = now;
    fn(...args);
  };
};

// toggle function
const toggleTheme = useMemo(
  () =>
    throttle(
      () =>
        setCurrentTheme(current =>
          current === "dark"
            ? "light"
            : "dark"
        ),
      THROTTLE_DELAY
    ),
  [THROTTLE_DELAY]
);
```
Wrapping the throttled function inside useMemo ensures it is created only when necessary while still allowing the delay to remain configurable.

# Step 5: Building the UI

Because the hook already contains all the business logic, the component becomes very small.
```
const {
    currentTheme,
    toggleTheme
} = useTheme();
```
Switching the icon becomes a simple conditional.

```
{currentTheme === "dark"
    ? <Sun />
    : <Moon />}
```

The component also supports keyboard navigation.
```
onKeyDown={(e) => {
    if (e.key !== "Enter") return;
    toggleTheme();
}}
```
Combined with an ARIA label, the toggle remains accessible for keyboard and screen reader users.

# Step 6: Testing

The logic and UI are tested independently.

The hook verifies the business logic.

```
renderHook(() => useTheme());

expect(result.current.currentTheme)
    .toBe("dark");
```

The component verifies user interaction.

```
await userEvent.click(button);

expect(document.documentElement)
    .not.toHaveClass("dark");
```

We also verify the throttle behavior by ensuring rapid consecutive clicks don't trigger multiple theme changes.

# Final Implementation

Now that every individual piece has been explained, here's the complete implementation.

* useTheme.ts

```
import { useEffect, useMemo, useState } from "react";
import { throttle } from "../../shared/lib/constants";

const THEME_STORAGE_KEY = "theme";

type TTheme = "light" | "dark";

interface UseThemeProps {
  THROTTLE_DELAY?: number;
}

export interface UseThemeReturns {
  currentTheme: TTheme;
  toggleTheme: () => void;
}

const fetchInitialTheme = (): TTheme => {
  try {
    const localTheme = localStorage.getItem(THEME_STORAGE_KEY);
    if (localTheme && ["light", "dark"].includes(localTheme))
      return localTheme as TTheme;
    const matchMedia = window.matchMedia("(prefers-color-scheme: dark)");
    if (matchMedia.matches) return "dark";
    return "light";
  } catch (err) {
    console.log(err);
    return "light";
  }
};

export default function useTheme(props: UseThemeProps | void): UseThemeReturns {
  const [currentTheme, setCurrentTheme] = useState<TTheme>(fetchInitialTheme);
  const { THROTTLE_DELAY = 1000 } = props || { THROTTLE_DELAY: 1000 };

  useEffect(() => {
    try {
      localStorage.setItem(THEME_STORAGE_KEY, currentTheme);
      document.documentElement.classList.toggle(
        "dark",
        currentTheme === "dark",
      );
    } catch (err) {
      console.warn(err);
    }
  }, [currentTheme]);

  const toggleTheme = useMemo(
    () =>
      throttle(
        () =>
          setCurrentTheme((currentTheme) =>
            currentTheme === "dark" ? "light" : "dark",
          ),
        THROTTLE_DELAY,
      ),
    [THROTTLE_DELAY],
  );

  return { currentTheme, toggleTheme };
}
```

* Theme.tsx

```
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome";
import { faMoon, faSun } from "@fortawesome/free-solid-svg-icons";
import useTheme from "./useTheme";

export default function Theme() {
  const { currentTheme, toggleTheme } = useTheme();

  return (
    <div
      onClick={toggleTheme}
      onKeyDown={(e: React.KeyboardEvent) => {
        if (e.key !== "Enter") return;
        toggleTheme();
      }}
      role="button"
      aria-label={`Switch to ${currentTheme === "dark" ? "light" : "dark"} mode`}
      className="w-fit h-full flex items-center cursor-pointer hover:scale-110 transition-all duration-400"
      tabIndex={0}
    >
      {currentTheme === "dark" ? (
        <FontAwesomeIcon icon={faSun} fontSize={18} />
      ) : (
        <FontAwesomeIcon icon={faMoon} fontSize={18} />
      )}
    </div>
  );
}
```

* Theme.test.tsx

```
import { cleanup, render, renderHook, screen } from "@testing-library/react";
import { afterEach, beforeEach, describe, expect, test } from "vitest";
import userEvent from "@testing-library/user-event";
import Theme from "./Theme";
import type { UseThemeReturns } from "./useTheme";
import useTheme from "./useTheme";
import { act } from "react";

describe("<Theme />", () => {
  let button: HTMLButtonElement;
  beforeEach(() => {
    localStorage.clear();
    localStorage.setItem("theme", "dark");
    render(<Theme />);
    button = screen.getByRole("button");
    userEvent.setup();
  });
  afterEach(() => {
    cleanup();
  });

  test("testing button and default theme at mount point", () => {
    expect(button).toBeInTheDocument();
    expect(document.documentElement).toHaveClass("dark");
  });

  test("testing toggling theme, throttle and then toggling theme again", async () => {
    // switching to light mode
    await userEvent.click(button);
    expect(document.documentElement).not.toHaveClass("dark");

    // testing throttle
    await userEvent.click(button);
    expect(document.documentElement).not.toHaveClass("dark");

    // testing toggling back to dark mode
    await new Promise((res) => setTimeout(() => res("done"), 1100));
    await userEvent.click(button);
    expect(document.documentElement).toHaveClass("dark");
  });
});

describe("useTheme.ts", () => {
  let result: { current: UseThemeReturns };
  beforeEach(() => {
    localStorage.clear();
    localStorage.setItem("theme", "dark");
    result = renderHook(() => useTheme()).result;
  });

  test("initial value", () => {
    expect(result.current.currentTheme).toBe("dark");
    act(() => result.current.toggleTheme());
    expect(result.current.currentTheme).toBe("light");
  });
});
```

# 日本語
ほとんどのダークモードチュートリアルは、CSSクラスの切り替えで終わってしまいます。

しかし、実際の運用環境では、以下のようないくつかの課題が存在します。
* ユーザー設定の保持
* オペレーティングシステムのテーマとの互換性の確保
* 頻繁な切り替え操作の防止
* 実装の再利用性の維持
* アクセシビリティの維持
* 動作テスト

この実装では、再利用可能なカスタムフックを使用することで、これらの課題すべてに対応しています。

# ステップ1：フックの設計

コンポーネント内にロジックを配置するのではなく、すべて専用のフック内に記述します。

このフックは非常にシンプルなAPIを提供します。
```
type TTheme = "light" | "dark";
export interface UseThemeReturns {
  currentTheme: TTheme;
  toggleTheme: () => void;
}
```
現在のテーマと切り替え機能のみを公開することで、プレゼンテーション層は実装から完全に独立した状態を維持します。

# ステップ2：初期テーマの決定

アプリケーションの起動時に、まず前回選択されたテーマを復元しようと試みます。
```
const THEME_STORAGE_KEY = "theme";

const fetchInitialTheme = (): TTheme => {
  const localTheme = localStorage.getItem(THEME_STORAGE_KEY);

  if (localTheme && ["light", "dark"].includes(localTheme))
    return localTheme as TTheme;
};
```
保存された設定がない場合は、ブラウザが優先する配色を使用します。

```
const matchMedia = window.matchMedia(
  "(prefers-color-scheme: dark)"
);

if (matchMedia.matches)
  return "dark";

return "light";
```
これにより、初めてサイトを訪れたユーザーは、オペレーティングシステムレベルで既に使用しているテーマを自動的に受け取ることができます。

# ステップ3：テーマ変更の保存

テーマが変更されるたびに、次の2つの処理が必要です。
* 設定を保存する
* ドキュメントルートを更新する
````
useEffect(() => {
  localStorage.setItem(
    THEME_STORAGE_KEY,
    currentTheme
  );

  document.documentElement.classList.toggle(
    "dark",
    currentTheme === "dark"
  );
}, [currentTheme]);
````
<html>要素を使用することで、Tailwindのdark:バリアントをアプリケーション全体で追加設定なしで使用できます。

# ステップ4：テーマの高速切り替えの防止

ユーザーは想定よりもはるかに速くクリックする可能性があります。

そのため、状態の更新が何十回も行われるのを防ぐため、切り替え操作を制限します。
```
// Throttle
export const throttle = <T extends (...args: unknown[]) => unknown>(
  fn: T,
  cooldown: number = 1000,
) => {
  let lastCalled: number = 0;
  return (...args: Parameters<T>) => {
    const now = Date.now();
    if (now - lastCalled < cooldown) return;
    lastCalled = now;
    fn(...args);
  };
};

// toggle function
const toggleTheme = useMemo(
  () =>
    throttle(
      () =>
        setCurrentTheme(current =>
          current === "dark"
            ? "light"
            : "dark"
        ),
      THROTTLE_DELAY
    ),
  [THROTTLE_DELAY]
);
```
スロットリングされた関数をuseMemoでラップすることで、必要な場合にのみ関数が作成されるようにしつつ、遅延時間を設定可能にすることができます。

# ステップ5：UIの構築

フックには既にすべてのビジネスロジックが含まれているため、コンポーネントは非常に小さくなります。
```
const {
    currentTheme,
    toggleTheme
} = useTheme();
```
アイコンの切り替えは、単純な条件分岐になります。
```
{currentTheme === "dark"
    ? <Sun />
    : <Moon />}
```

このコンポーネントはキーボード操作にも対応しています。
```
onKeyDown={(e) => {
    if (e.key !== "Enter") return;
    toggleTheme();
}}
```
ARIAラベルと組み合わせることで、このトグルはキーボードユーザーとスクリーンリーダーユーザーの両方にとってアクセス可能な状態を維持します。

# ステップ6：テスト

ロジックとUIはそれぞれ独立してテストされます。

フックはビジネスロジックを検証します。

```

    .toBe("dark");
```

このコンポーネントは、ユーザーの操作を検証します。
```

    .not.toHaveClass("dark");
```

また、連続した素早いクリックによって複数のテーマ変更がトリガーされないことを確認することで、スロットル動作の検証も行いました。
