# English Version

This article presents a clean and flexible implementation of a headless modal component built from scratch in React.

The idea is inspired by the design behind headless component libraries such as Headless UI: separating logic, accessibility, and animation from visual styling so developers can fully control the UI.

This implementation consists of three main parts:

• A custom hook (useModal) that manages modal state and accessibility behavior
• A wrapper modal component that handles rendering and animations
• Portal rendering to ensure the modal is mounted outside the normal DOM tree

Animations are powered by Motion, while accessibility behaviors such as focus trapping, scroll prevention, and Escape key closing are implemented manually.

This pattern is particularly useful when:

• You want full styling freedom instead of relying on UI libraries
• You want reusable modal logic that can be shared across components
• You want to guarantee accessibility behaviors such as focus management and keyboard navigation

Step 1: The useModal Hook – Core State and References

We start by creating a hook responsible for controlling the modal state and handling accessibility concerns.

The hook exposes:

• openModal – opens the modal
• closeModal – closes the modal
• modalRef – reference to the modal container
• triggerRef – reference to the trigger element
• isOpen – modal visibility state

```ts
interface UseModalProps {
  trapFocus?: boolean;
  preventScroll?: boolean;
}

interface UseModalReturns<T extends HTMLElement, M extends HTMLElement> {
  openModal: () => void;
  closeModal: () => void;
  modalRef: RefObject<M | null>;
  triggerRef: RefObject<T | null>;
  isOpen: boolean;
}
```

This hook allows the modal component to remain headless, while the logic stays isolated and reusable.

Step 2: Defining Focusable Elements

To properly implement focus trapping, we first define a selector that matches all elements that can receive keyboard focus.

```ts
const FOCUSABLE_SELECTOR = [
  "a[href]",
  "button:not([disabled])",
  'input:not([disabled]):not([type="hidden"])',
  "select:not([disabled])",
  "textarea:not([disabled])",
  '[tabindex]:not([tabindex="-1"])',
].join(",");
```

This selector allows us to collect all focusable elements inside the modal and control keyboard navigation.

Step 3: Opening the Modal and Preparing Accessibility Behavior

When the modal opens, several things happen:

• The currently focused element is saved
• Page scrolling can optionally be disabled
• Focus moves to the first focusable element inside the modal
• Keyboard listeners are attached

```ts
const openModal = useCallback(() => setIsOpen(true), []);
const closeModal = useCallback(() => setIsOpen(false), []);
```

Inside useEffect, we manage these behaviors when isOpen becomes true.

```ts
useEffect(() => {
  if (!isOpen) return;

  const modal = modalRef.current;

  const handleEscapeKey = (e: KeyboardEvent) => {
    if (e.key === "Escape") closeModal();
  };

  const previousOverflow = document.body.style.overflow;

  if (preventScroll) {
    document.body.style.overflow = "hidden";
  }

  lastActiveElement.current = document.activeElement;
```

This ensures the modal behaves correctly both visually and from a keyboard navigation perspective.

Step 4: Implementing Focus Trap

To maintain accessibility, keyboard navigation should remain inside the modal while it is open.

```ts
const handleFocusTrap = (e: KeyboardEvent) => {
  if (e.key !== "Tab" || !trapFocus) return;

  const first = focusables[0];
  const last = focusables[focusables.length - 1];
  const active = document.activeElement as HTMLElement | null;

  if (!active || !modal.contains(active)) {
    e.preventDefault();
    first.focus();
    return;
  }

  if (!e.shiftKey && active === last) {
    e.preventDefault();
    first.focus();
    return;
  }

  if (e.shiftKey && active === first) {
    e.preventDefault();
    last.focus();
  }
};
```

This keeps keyboard navigation cycling within the modal elements.

Step 5: Cleaning Up on Close

When the modal closes:

• Event listeners are removed
• Scroll behavior is restored
• Focus returns to the original trigger element

```ts
return () => {
  modal.removeEventListener("keydown", handleFocusTrap);
  window.removeEventListener("keydown", handleEscapeKey);
  document.body.style.overflow = previousOverflow;

  if (lastActiveElement.current instanceof HTMLElement) {
    lastActiveElement.current.focus();
  }
};
```

This ensures the modal behaves correctly in both accessibility and UX terms.

Step 6: Creating the Modal Wrapper Component

The wrapper component connects the hook logic with rendering.

Key responsibilities:

• Render the trigger element
• Render the modal content
• Handle animations
• Render using a portal

```ts
interface ModalProps {
  trigger: React.ReactNode;
  children: React.ReactNode;
  trapFocus?: boolean;
  preventScroll?: boolean;
  duration?: number;
}
```

The trigger is wrapped so we can attach the reference and click handler.

```ts
<TriggerWrapper ref={triggerRef} onClick={openModal}>
  {trigger}
</TriggerWrapper>
```

Step 7: Rendering the Modal with a Portal

To avoid layout and stacking issues, the modal is rendered directly inside document.body using a portal.

```ts
createPortal(
  <AnimatePresence>
    {isOpen && (
      <FullScreenLayer>
        <ChildrenMotion
          ref={modalRef}
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
          transition={{ duration }}
          exit={{ opacity: 0 }}
          role="dialog"
          aria-modal="true"
        >
          {children}
        </ChildrenMotion>
      </FullScreenLayer>
    )}
  </AnimatePresence>,
  document.body
)
```

This ensures the modal appears above the entire application.

Final Complete Implementation
* useModal.ts
```ts
import {
  useCallback,
  useEffect,
  useRef,
  useState,
  type RefObject,
} from "react";

const FOCUSABLE_SELECTOR = [
  "a[href]",
  "button:not([disabled])",
  'input:not([disabled]):not([type="hidden"])',
  "select:not([disabled])",
  "textarea:not([disabled])",
  '[tabindex]:not([tabindex="-1"])',
].join(",");

interface UseModalProps {
  trapFocus?: boolean;
  preventScroll?: boolean;
}

interface UseModalReturns<T extends HTMLElement, M extends HTMLElement> {
  openModal: () => void;
  closeModal: () => void;
  modalRef: RefObject<M | null>;
  triggerRef: RefObject<T | null>;
  isOpen: boolean;
}

export default function useModal<T extends HTMLElement, M extends HTMLElement>(
  props?: UseModalProps,
): UseModalReturns<T, M> {
  const { trapFocus = true, preventScroll = true } = props ?? {};
  const triggerRef = useRef<T | null>(null);
  const modalRef = useRef<M | null>(null);
  const lastActiveElement = useRef<Element | null>(null);
  const [isOpen, setIsOpen] = useState<boolean>(false);

  const openModal = useCallback(() => setIsOpen(true), []);

  const closeModal = useCallback(() => setIsOpen(false), []);

  useEffect(() => {
    if (!isOpen) return;
    if (!modalRef.current || !triggerRef.current) return;
    const modal = modalRef.current;
    const handleEscapeKey = (e: KeyboardEvent) => {
      if (e.key !== "Escape") return;
      closeModal();
    };
    const previousOverflow = document.body.style.overflow;
    if (preventScroll) {
      document.body.style.overflow = "hidden";
    }
    lastActiveElement.current = document.activeElement;
    const focusables = Array.from(
      modal.querySelectorAll<HTMLElement>(FOCUSABLE_SELECTOR),
    ).filter(
      (el) => !el.hasAttribute("disabled") && !el.getAttribute("aria-hidden"),
    );
    focusables[0]?.focus();
    console.log(focusables[0]);
    const handleFocusTrap = (e: KeyboardEvent) => {
      if (e.key !== "Tab" || !trapFocus) return;
      if (focusables.length < 2) return;
      const first = focusables[0];
      const last = focusables[focusables.length - 1];
      const active = document.activeElement as HTMLElement | null;
      if (!active || !modal.contains(active)) {
        e.preventDefault();
        first.focus();
        return;
      }
      if (!e.shiftKey && active === last) {
        e.preventDefault();
        first.focus();
        return;
      }
      if (e.shiftKey && active === first) {
        e.preventDefault();
        last.focus();
        return;
      }
    };
    modal.addEventListener("keydown", handleFocusTrap);
    window.addEventListener("keydown", handleEscapeKey);
    return () => {
      modal.removeEventListener("keydown", handleFocusTrap);
      window.removeEventListener("keydown", handleEscapeKey);
      document.body.style.overflow = previousOverflow;
      if (lastActiveElement.current instanceof HTMLElement) {
        lastActiveElement.current!.focus();
      }
    };
  }, [isOpen, trapFocus, closeModal, preventScroll]);

  return { openModal, closeModal, modalRef, triggerRef, isOpen };
}

```


* Modal.tsx
```ts
import { Box, styled } from "@mui/material";
// I am using Mui for styling, but feel free to use any other library
import useModal from "./useModal";
import { AnimatePresence, motion } from "motion/react";
import { createPortal } from "react-dom";

interface ModalProps {
  trigger: React.ReactNode;
  children: React.ReactNode;
  trapFocus?: boolean;
  preventScroll?: boolean;
  duration?: number;
}

const TriggerWrapper = styled(Box)({
  display: "inline-block",
});

const ChildrenWrapper = styled(Box)({
  display: "inline-block",
  border: "1px solid black",
  zIndex: 999,
  color: "black",
});

const ChildrenMotion = motion.create(ChildrenWrapper);

const FullScreenLayer = styled(Box)({
  position: "fixed",
  width: "100vw",
  height: "100vh",
  inset: 0,
  zIndex: 12,
  display: "flex",
  justifyContent: "center",
  alignItems: "center",
  backdropFilter: "blur(10px)",
});

export default function Modal({
  trigger,
  children,
  trapFocus,
  preventScroll,
  duration = 0.2,
}: ModalProps) {
  const { isOpen, openModal, triggerRef, modalRef } = useModal({
    trapFocus,
    preventScroll,
  });

  return (
    <>
      <TriggerWrapper ref={triggerRef} onClick={openModal}>
        {trigger}
      </TriggerWrapper>
      {createPortal(
        <AnimatePresence>
          {isOpen && (
            <FullScreenLayer>
              <ChildrenMotion
                ref={modalRef}
                initial={{ opacity: 0 }}
                animate={{ opacity: 1 }}
                transition={{ duration }}
                exit={{ opacity: 0 }}
                role="dialog"
                aria-modal="true"
              >
                {children}
              </ChildrenMotion>
            </FullScreenLayer>
          )}
        </AnimatePresence>,
        document.body,
      )}
    </>
  );
}
```

# 日本語版

この記事では、React を使って ヘッドレスモーダルコンポーネントをゼロから実装する方法を紹介します。

このアイデアは Headless UI のようなヘッドレスコンポーネントライブラリの設計思想に影響を受けています。
つまり、ロジック・アクセシビリティ・アニメーションを UI のスタイリングから分離することで、開発者が UI を完全に自由にコントロールできるようにするという考え方です。

今回の実装は次の3つの要素で構成されています：

• モーダルの状態管理とアクセシビリティ動作を担当する カスタムフック (useModal)
• レンダリングとアニメーションを担当する モーダルラッパーコンポーネント
• モーダルを通常の DOM ツリーの外に配置するための Portal レンダリング

アニメーションには Motion を使用し、
フォーカストラップ・スクロール防止・Escape キーでのクローズなどのアクセシビリティ動作は手動で実装しています。

このパターンが特に役立つ場面：

• UI ライブラリに依存せず スタイリングを完全に自由にしたい場合
• 再利用可能なモーダルロジックを複数コンポーネントで共有したい場合
• フォーカス管理やキーボード操作などのアクセシビリティ動作を確実に実装したい場合

Step 1: useModal フック – 状態管理と参照の定義

まず、モーダルの状態管理とアクセシビリティ処理を担当する カスタムフックを作成します。

このフックは次の値を返します：

• openModal – モーダルを開く
• closeModal – モーダルを閉じる
• modalRef – モーダルコンテナの参照
• triggerRef – トリガー要素の参照
• isOpen – モーダルの表示状態

```ts
interface UseModalProps {
```

このフックによって、モーダルコンポーネントはヘッドレスのままに保たれ、ロジックは独立した再利用可能な形になります。

```ts
  justifyContent: "center",
  alignItems: "center",
  backdropFilter: "blur(10px)",
});

export default function Modal({
  trigger,
  children,
  trapFocus,
  preventScroll,
  duration = 0.2,
}: ModalProps) {
  const { isOpen, openModal, triggerRef, modalRef } = useModal({
    trapFocus,
    preventScroll,
  });

  return (
    <>
      <TriggerWrapper ref={triggerRef} onClick={openModal}>
        {trigger}
      </TriggerWrapper>
      {createPortal(
        <AnimatePresence>
          {isOpen && (
            <FullScreenLayer>
              <ChildrenMotion
                ref={modalRef}
                initial={{ opacity: 0 }}
                animate={{ opacity: 1 }}
                transition={{ duration }}
                exit={{ opacity: 0 }}
                role="dialog"
                aria-modal="true"
              >
                {children}
              </ChildrenMotion>
            </FullScreenLayer>
          )}
        </AnimatePresence>,
        document.body,
      )}
    </>
  );
}
```
